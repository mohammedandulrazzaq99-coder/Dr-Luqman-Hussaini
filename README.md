# Dr. Syed Ali Luqman Hussaini — Official Website

Official multi-page website for **Dr. Syed Ali Luqman Hussaini** — Educator, Educational Leader, Trainer, and Researcher across Education, Leadership Development, Psychology, and Human Resource Management.

---

## 🌐 Pages Overview

1. **Home (`index.html`)** — Hero showcase, professional identity, core domains, and institutional highlights.
2. **About (`about.html`)** — Academic bio, multi-disciplinary approach, philosophy, and personal statement.
3. **Expertise (`expertise.html`)** — 5 specialized focus areas with in-depth practice pillars and methodology.
4. **Journey (`journey.html`)** — Compact interactive vertical timeline charting key milestones from academic foundations to institutional leadership.
5. **Research & Ideas (`research.html`)** — Academic publications, doctoral thesis details, corporate case studies, and ongoing inquiries.
6. **Keynotes & Speaking (`speaking.html`)** — Keynote lectures, executive workshops, university addresses, and session topics.
7. **Media & Gallery (`media.html`)** — Video dialogues, photo archives, and public engagements.
8. **Credentials & Honors (`credentials.html`)** — Academic qualifications, institutional affiliations, and awards.
9. **Professional Inquiry (`inquiry.html`)** — Direct contact, speaking invitations, and institutional advisory inquiries.

---

## ✨ Features & Technology

- **Responsive Design**: Built with Tailwind CSS for seamless viewing on desktop, tablet, and mobile devices.
- **Scroll Fill Timeline Track**: 4px high-visibility blue gradient scroll-driven fill animations.
- **Face-Focus Image Framing**: Universal CSS focal positioning ensuring Dr. Luqman's face is clearly framed and visible in all card sizes and aspect ratios.
- **Micro-Interactions**: Header backdrop blur, subtle card hover elevation (`hover-lift`), and button arrow animations.
- **Zero External Framework Dependencies**: Pure HTML5, CSS3, and vanilla JavaScript.

## 🚀 Running Locally

To run the local HTTP server:

```bash
node local-server.js
```

Then open your browser and visit:
```
http://localhost:3000/
```
